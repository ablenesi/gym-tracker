Gym Coach Tracker

Private, synced version. Sign in with your GitHub access token to continue.

How to create the token (one-off, ~2 min)
  1. Open github.com/settings/personal-access-tokens/new (signed in as ablenesi).
  2. Name it e.g. “Gym tracker”. Expiration: No expiration (or the longest allowed).
  3. Repository access: Only select repositories → gym-tracker-data.
  4. Repository permissions → Contents: Read and write (Metadata: Read-only is added automatically). Nothing else.
  5. Generate, copy the token and paste it above. Do the same paste on each phone/computer you use.

The token is stored only in this browser. “Sign out” removes it from the device.
